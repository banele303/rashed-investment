# Rashed Investments Website

This is the repository for the Rashed Investments website, a premium 5-page Vite + React web application.

## Technologies Used
- React 18
- Vite
- Vanilla CSS with a custom luxury dark-gold design system
- React Router DOM
- Lucide React (Icons)

## Development
To run this project locally:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Build
To build the project for production:
```bash
npm run build
```
